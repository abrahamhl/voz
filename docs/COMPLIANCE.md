# Compliance status

A working checklist of the rules VOZ must meet, what the code already does, and what remains. Sources were read on
2026-09-23. **This is an engineering summary, not legal advice**; items marked [COUNSEL] need a qualified lawyer.

| Rule | Source | VOZ today | Open |

## 2. Google Gemini API (cloud brain)

| Rule | Source | VOZ today |
|---|---|---|
| Professional or business use only, not consumer use; users must be 18+; not for services directed at minors | [Gemini API Additional Terms](https://ai.google.dev/gemini-api/terms) (effective 2026-03-23) | The cloud brain is compiled out of release builds (`cloud_brain_available`). Pilot builds keep it for adult testers with their own key. |
| Only Paid Services when making API clients available to users in the EEA, Switzerland or the UK | Same | Consent screen v2 states it. Release builds don't include the feature. |
| Unpaid content may be used to improve Google products and read by human reviewers; don't submit sensitive or personal data | Same | Masking of e-mail, IBAN, codes, phone and card numbers; on-phone brains first; the app name is not sent; the consent screen warns against banking, health and chat screens |

Offering cloud planning to consumers would need a VOZ-operated paid backend with a data processing agreement. That is
an owner decision (costs, servers, legal entity) [COUNSEL].

## 3. On-device AI (evaluated, not adopted)

ML Kit GenAI (Gemini Nano) Prompt API is beta and device-limited, and inference is blocked unless the app is the top
foreground app, including from a foreground service ([ML Kit GenAI](https://developers.google.com/ml-kit/genai)).
VOZ acts while other apps are in front, so this path doesn't fit its core use.

## 4. EU General Data Protection Regulation

- VOZ processes screen text, speech transcripts and the history **on the device only**. The publisher receives no
  personal data. No analytics, crash reporting or ads SDKs.
- Data minimisation: dictated or unrecognised speech is stored only as a character count; the history is capped at
  200 entries; backups and device transfer are excluded.
- Accessibility use can reveal a disability (special-category data). Nothing leaves the phone in release builds. A
  managed cloud service would need a lawful basis, a DPIA and processor terms [COUNSEL].

## 5. EU AI Act

- Article 50 (transparency for AI systems that interact with people) applies from **2 August 2026**
  ([AI Act Explorer](https://artificialintelligenceact.eu/article/50/)). In pilot builds, replies generated by
  Gemini are spoken as "Gemini says …" and marked "Cloud (Gemini)" on screen.
- Release builds use a rule-based command grammar and simple on-device heuristics. Whether these count as an "AI
  system" under Article 3(1) is [COUNSEL].

## 6. Accessibility of VOZ itself

The European Accessibility Act covers listed products and services such as smartphones, operating systems, banking and
e-commerce ([European Commission](https://commission.europa.eu/strategy-and-policy/policies/justice-and-fundamental-rights/disability/union-equality-strategy-rights-persons-disabilities-2021-2030/european-accessibility-act_en)).
Whether a standalone assistive app is in scope is [COUNSEL]. VOZ aims for WCAG 2.2 AA anyway:

| WCAG 2.2 | How VOZ addresses it | Verified |
|---|---|---|
| 1.4.1 Use of colour | Every state has an icon and words; the bubble has a TalkBack state description | Code review |
| 1.4.3 / 1.4.11 Contrast | Colour tokens with computed ratios (text ≥ 4.5:1, borders and icons ≥ 3:1) in light, dark and high contrast | Computed, not measured on device |
| 1.4.4 / 1.4.10 Resize and reflow | No fixed heights around text, no text inside the orb, scrolling screens, landscape two-pane | Not checked at 200 % on a device |
| 1.3.4 Orientation | Portrait and landscape, no lock | Not checked on device |
| 2.5.7 Dragging movements | The floating mic can be moved with "Move left/right/up/down" actions | Not checked with TalkBack |
| 2.5.8 Target size | ≥ 48 dp everywhere, confirm buttons ≥ 64 dp, mic 120–200 dp | Code review |
| 4.1.3 Status messages | Permission status changes are polite live regions; nothing is announced while the mic is open | Not checked with TalkBack |
| 2.2.1 Timing | A voice confirmation times out after two listens and cancels (safety). The on-screen Yes/No stays until then. | Design choice, documented |
